Dataiku provides an enterprise AI and analytics platform that empowers data teams to collaboratively prepare data, build predictive models, and deploy AI-driven applications at scale. The platform integrates data engineering, machine learning, and operationalization tools, offering a unified environment for data scientists, analysts, and business users to turn data into actionable insights. It supports a wide range of use cases from data preparation to model monitoring, enabling organizations to accelerate AI adoption across the enterprise.

**Areas:** Analytics · Artificial Intelligence · Data Platform · Data Science · Machine Learning

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Dataiku: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
